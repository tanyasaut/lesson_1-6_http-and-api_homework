# Backend

Приложение для работы с коллекцией фильмов. Данные хранятся в локальном REST API (json-server)

## Стек и инструменты
- **Frontend:** HTML, CSS, JavaScript (Fetch API, DOM)
- **Backend:** `json-server` (Node.js)
- **Запуск:** VS Code + Live Server

## Тема и ресурс
- **Предметная область:** Каталог фильмов
- **Ресурс (endpoint):** `http://localhost:3000/movies`
- **Свойства объекта:** 
  - `title` — название 
  - `director` — режиссер 
  - `year` — год выпуска 
  - `rating` — рейтинг

## Запуск

```bash
npm install
npm run dev
```
